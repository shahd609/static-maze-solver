# Static Maze Solver: BFS vs. Genetic Algorithm

## Overview
This project explores two approaches to solving a static 10×10 maze: Breadth-First Search (BFS) and a Genetic Algorithm (GA). It compares a traditional search algorithm with an evolutionary approach to finding a path through a maze.

## Algorithms Used
- **Breadth-First Search (BFS):** Explores the maze level by level to find the shortest path in an unweighted maze.
- **Genetic Algorithm (GA):** Uses an evolutionary process to search for a solution through candidate paths and a mutation operator.

## Technologies
- Python
- NumPy
- Matplotlib

## Key Features
- Solves a 10×10 maze using two different approaches.
- Implements a 5% mutation rate in the Genetic Algorithm.
- Tests and compares the behavior of BFS and the Genetic Algorithm.

## Project Goals
- Understand the differences between traditional search and evolutionary algorithms.
- Evaluate the approaches when solving a maze.
- Document the results and compare the algorithms.

## How to Run
1. Clone or download this repository.
2. Make sure Python is installed.
3. Install the required libraries, if needed:

   ```bash
   pip install numpy matplotlib
   ```

4. Run the main Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual name of your Python file.
